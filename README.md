# Retro'98 Study Desk

A retro Windows 98-inspired studying app built with vanilla HTML, CSS, and JavaScript. Organize your study sessions, take notes, and stay motivated in nostalgic style.

## Features

- **Study Planner** – add, complete, and delete tasks with local storage persistence.
- **Pomodoro Timer** – choose 15, 25, or 45-minute focus sessions with progress tracking.
- **Sticky Notes** – jot down quick notes and save them in your browser.
- **Motivation.exe** – pull a random motivational quote whenever you need a boost.
- **Retro Interface** – Windows 98-inspired UI complete with a faux taskbar clock.

## Getting Started

1. Open `index.html` directly in your browser, or serve the project locally (for example, `python -m http.server`).
2. Interact with the planner, timer, notes, and quotes. Data is saved to `localStorage` so it persists between visits in the same browser.

## Development

The project is fully static. Edit `index.html`, `style.css`, or `script.js` to customize the experience. No build tools required.
